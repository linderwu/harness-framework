# A2A v0.3 Durable Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add durable A2A v0.3 message/task/event records, preserve raw protocol frames, persist manager/worker handoffs, and expose a standards-shaped authenticated A2A server.

**Architecture:** Extend the existing SQLite WAL repository with typed A2A message, task, and event projections. Route all outbound and inbound exchanges through a small runtime recorder that redacts secrets, hashes frames, enforces idempotency, and appends ordered lifecycle events. Keep the existing OpenClaw command adapter for compatibility while adding v0.3 JSON-RPC discovery, send, stream, get, and cancel routes.

**Tech Stack:** Next.js 16 route handlers, TypeScript, better-sqlite3 WAL, Node test runner, existing workflow/manager/conversation services.

  ```sql

    id TEXT PRIMARY KEY,
    workflow_run_id TEXT,
    context_id TEXT NOT NULL,
    remote_task_id TEXT,
    from_agent TEXT NOT NULL,
    to_agent TEXT NOT NULL,
    status TEXT NOT NULL,
    request_message_id TEXT NOT NULL UNIQUE,
    idempotency_key TEXT NOT NULL UNIQUE,
    error_code TEXT,
    error_message TEXT,

    updated_at TEXT NOT NULL,

  CREATE TABLE a2a_messages (
    id TEXT PRIMARY KEY,
    task_id TEXT,
    context_id TEXT NOT NULL,
    parent_message_id TEXT,
    direction TEXT NOT NULL,
    from_agent TEXT NOT NULL,
    to_agent TEXT NOT NULL,
    protocol_version TEXT NOT NULL,
    method TEXT NOT NULL,
    transport TEXT NOT NULL,
    idempotency_key TEXT,
    request_json TEXT NOT NULL,
    response_json TEXT,
    request_sha256 TEXT NOT NULL,
    response_sha256 TEXT,
    created_at TEXT NOT NULL,
    sent_at TEXT,
    received_at TEXT

  CREATE TABLE a2a_events (
    id TEXT PRIMARY KEY,
    task_id TEXT NOT NULL,
    message_id TEXT,
    sequence INTEGER NOT NULL,
    event_type TEXT NOT NULL,
    actor TEXT NOT NULL,
    payload_json TEXT NOT NULL,
    created_at TEXT NOT NULL,

  );
  ```

  Add indexes on `(context_id, created_at)`, `(task_id, sequence)`, and
  `(status, updated_at)`. Increment `hiveSchemaVersion` and keep migrations
  idempotent under the existing migration transaction pattern.
